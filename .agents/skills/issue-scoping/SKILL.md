# Issue scoping
Read AGENTS.md and current state first. Bugs: capture problem/impact, current vs
expected behavior, repro, evidence, affected flows, acceptance criteria,
non-goals, likely regressions, T0–T4 tier and completion evidence. Features:
capture outcome/context, user flow, in-scope behavior, dependencies/constraints,
non-goals, failure/edge states, acceptance criteria, likely regressions and
required verification. Acceptance criteria describe observable outcomes. Use
bm-prd-creator for a new app/major feature/new surface/epic. Resolve routine
ambiguity from evidence.
